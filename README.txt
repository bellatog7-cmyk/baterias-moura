BATERIAS MOURA — LANDING PAGE
==============================

Arquivos:
- index.html
- style.css
- script.js
- assets/hero-moura.png
- assets/logo-moura.png

WHATSAPP
--------
Abra o arquivo script.js e altere:

const WHATSAPP_NUMBER = "5500000000000";

Exemplo:
const WHATSAPP_NUMBER = "5599999999999";

Use somente números, com 55 + DDD + número.

PUBLICAÇÃO NA VERCEL
--------------------
1. Extraia o ZIP.
2. Acesse a Vercel.
3. Crie um novo projeto e envie a pasta do projeto (ou conecte um repositório).
4. Não é necessário Node.js ou build para esta versão.
5. O arquivo inicial é index.html.

OBSERVAÇÃO
-----------
A página usa as duas imagens fornecidas pelo cliente dentro da pasta assets.
